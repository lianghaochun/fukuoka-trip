# 旅遊行程規劃網頁
  (2026/12/27福岡)

### 流程

- 旅伴按「備份」→「匯出分享檔（.json）」，把檔案傳給你。
- 你在電腦上開網頁，按「匯入分享檔或備份檔」，選「只更新行程與資訊」。
你確認內容沒問題，按「下載離線網頁（分享版）」，用下載的檔案覆蓋上傳 GitHub（檔名要跟原本一樣）。
旅伴重新開啟網頁，會自動收到合併後的版本。

要注意的地方

旅伴的版本會蓋掉你的：匯入時，同一筆行程、餐廳、景點，以旅伴檔案裡的內容為準。如果你在他改完之後又改了同一筆，會被他的舊版蓋回去。
你的新增可能被刪：第一次匯入時，你自己新增、但旅伴檔案裡沒有的項目會被移除。匯入完會出現「復原」提示，請馬上檢查。
旅伴的備註會跟著進來：分享檔包含每日備註，所以旅伴寫在備註裡的個人記錄也會帶給你。你自己改過的備註不會被蓋掉，沒改過的會跟著更新。

建議的做法

旅伴要編輯前，先打開 GitHub 上最新的網頁，等它自動更新完再改。這樣他的版本是建立在你的最新版上。
他改完立刻傳給你，你也盡快匯入並上傳，中間你就不要改行程。
如果有兩位旅伴都要改，請一位一位來，不要同時匯入。
旅伴不想分享的個人備註，請他不要寫在每日備註裡，或匯出前先清掉。
